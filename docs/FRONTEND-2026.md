# تدقيق: سمات الواجهات الأمامية 2026 مقابل هذا المستودع

فحص فعلي للكود، لا مقارنة بقوائم مدونات. كل صف هنا تحقّق منه بأمر أو بقياس في المتصفح.

## تصحيح مهم في القائمة المتداولة

معظم المقالات المنشورة قبل أكتوبر 2026 تقول إن **Scroll-driven animations** غير مدعومة في Firefox. هذا **صار قديماً**: Firefox 159 أطلقها افتراضياً في **27 أكتوبر 2026**، فصارت Baseline Newly available. لذلك اعتمدناها هنا.

وكذلك، `sibling-index()` و`sibling-count()` صارتا Baseline في **18 أغسطس 2026** مع Firefox 154.

## بنود رفضتها عن قصد

| البند | السبب |
| --- | --- |
| RSC / SSR / Islands | الموقع ثابت على GitHub Pages. لا خادم يشغّلها. تبنيها يعني تغيير الاستضافة، لا تحديثاً |
| Signals | حالة التطبيق صغيرة (`useState` + context). إدخال مكتبة إشارات يضيف وزناً بلا مشكلة يحلّها |
| Micro Frontends | ثلاثة أدوات وفريق واحد. تعقيد بلا مقابل |
| WebAssembly | لا حساب ثقيل على العميل. الأدوات المحلية نصّية |
| PWA / Service Worker | التخزين محلي أصلاً. عامل خدمة يضيف مشكلة إبطال التخزين المؤقت تستحق قراراً منفصلاً |
| Angular zoneless / Svelte runes | أطر أخرى؛ المشروع React |
| Anchor positioning | لا توجد tooltips مخصّصة تحتاجه؛ `dialog` الأصلي يكفي |
| Cross-document View Transitions | الموقع SPA بمسار واحد، لا تنقّل بين مستندات |

## عيبان حقيقيان اكتشفهما التدقيق

**1. تتابع الظهور لم يكن يعمل إطلاقاً.** القواعد كانت تستهدف `.tool-cards > [data-reveal]` بينما البطاقات تحمل `data-tilt` فقط. صفر تطابق — أي أن التتابع الذي وُصف في PR #8 **لم يعمل ولا مرة**. أُصلح بإضافة السمتين، واستُبدل الترقيم اليدوي بـ`sibling-index()` ليعمل مع أي عدد أدوات.

**2. الكشف والميل يتصارعان على `transform`.** كلاهما يكتب الخاصية نفسها، فكلٌّ يلغي الآخر. فُصلا: الكشف يستخدم `translate` والميل يستخدم `transform` — خاصيتان مستقلتان تتراكبان.

**3. حاوية الاستعلام كانت على الشبكة لا البطاقة.** أول محاولة وضعت `container-type` على `.tool-cards` (747px)، فلم تتطابق أي عتبة بطاقة وبقيت قاعدة نافذة العرض القديمة تفوز. القياس أثبت ذلك: `h3 = 12px` عند عرض 1000px. بعد نقل الحاوية إلى البطاقة نفسها: 359px→15px، 242px→13px، จอล 356px→18px.

## حدود الحزمة

الحد الأقصى على Pages هو 1 GB، وهو **لا يمسك حزمة متضخمة أبداً**. أُضيف حد مستقل مقيس على البايتات المضغوطة التي ينزّلها الزائر فعلاً:

| النوع | الحالي | الحد |
| --- | --- | --- |
| JS (gzip) | 171.3 KB | 200 KB |
| CSS (gzip) | 29.4 KB | 40 KB |

اختُبر الحد سلبيّاً: خفضه إلى 1 KB أفشل البناء بـ`budget_exceeded_js`.

## قاعدة الاعتماد

- **Baseline Widely available** (Container Queries، `:has()`، Nesting): تُستخدم بلا بديل.
- **Baseline Newly available** (`animation-timeline`، `sibling-index()`): تُستخدم داخل `@supports` مع بديل يعمل.
- **غير مدعومة عالمياً** (cross-document transitions، anchor positioning): لا تُستخدم.

كل مسار له اختبار يتحقق أن الميزة **مطبّقة فعلاً** في المتصفح، لا موجودة في المصدر فقط.
