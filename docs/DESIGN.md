# الهوية البصرية والموشن — celia.sh

الواجهة تحمل الاسم الجديد `celia.sh` كأساس، مع سطر عربي صغير تحته. كل الأسماء تأتي من إعدادات البيئة، فلا يوجد اسم مكتوب مباشرة في المكوّنات.

## أين يظهر الاسم

| الموضع | الشكل | المصدر |
| --- | --- | --- |
| الشريط الجانبي | شعار + `celia.sh` بحجم 25px + «لك · أدوات ذكية» | `site.brandLatin` + `site.brandAr` |
| أعلى الـHero | شعار 42px + `celia.sh` بحجم 34px | نفسه |
| شريط الجوال العلوي | `celia.sh` مصغّر — الشريط الجانبي مخفي على الجوال | نفسه |
| التذييل | `celia.sh` داخل الجملة | نفسه |
| عنوان التبويب | `celia.sh — أدوات ذكية، لاحتمالات أكبر` | `shared/site.ts` |
| بطاقة المشاركة | PNG مقاس 1200×630 | `scripts/render-og-image.mjs` |
| الأيقونة | حرف c مفتوح + شرارة | `public/favicon.svg` |

لتغيير الاسم لاحقاً: `VITE_BRAND_LATIN` و`VITE_BRAND_AR`. لا تعديل كود.

## طبقة الموشن

معزولة في `src/styles/identity.css` + `src/hooks/useMotion.ts`، وتُحمَّل بعد `styles.css` الأساسي.

| التأثير | الوصف | التعطيل التلقائي |
| --- | --- | --- |
| ميل البطاقات | حتى ±2.5 درجة تتبع المؤشر | مؤشر خشن (لمس) + تقليل الحركة |
| توهّج المؤشر | هالة بنفسجية تتبع المؤشر داخل البطاقة | نفسه |
| ظهور عند التمرير | `IntersectionObserver` بتتابع 70ms | تقليل الحركة |
| لمعة الشعار | تمر كل 7 ثوانٍ | تقليل الحركة |
| انسياب خلف الـHero | تدرّج يتحرك كل 26 ثانية | تقليل الحركة |
| نبض نقطة الحالة | كل 3.4 ثانية | تقليل الحركة |
| ضغط الأزرار | `scale(.975)` عند الضغط | تقليل الحركة |

### قواعد السلامة

- **المحتوى لا يختفي أبداً**: عناصر الظهور تُخفى فقط بعد أن يسلّحها JavaScript (`reveal-armed`). لو فشل السكربت أو غاب `IntersectionObserver` أو فعّل المستخدم تقليل الحركة، يبقى كل شيء ظاهراً.
- **التفويض لا الربط المباشر**: مستمع `pointermove` واحد على `document` يخدم كل البطاقات، فتعمل البطاقات المضافة لاحقاً بلا إعادة ربط.
- **`requestAnimationFrame`**: كتابة المتغيرات مرة واحدة لكل إطار، لا لكل حدث مؤشر.
- **تنظيف الحالة**: مغادرة المؤشر أو فقدان تركيز النافذة يمسح المتغيرات، فلا تبقى بطاقة مائلة.
- **بلا `will-change` دائم**: يكلّف ذاكرة على كل بطاقة؛ الـ`transform` يرقّي الطبقة أثناء الحركة فقط.

## التباين

كل لون نص معدّل مقيس بنسبة **4.5:1** أو أفضل مقابل خلفيته الفعلية، في الوضعين. الفحوص الآلية (axe) تمر على سبع صفحات × وضعين.

انتبه: رسوم الـHero ومعاينات البطاقات **تحتفظ بخلفياتها الفاتحة في الوضع الداكن** وتُخفَّت بـ`filter` لا بإعادة تلوين. لذلك نصّها يبقى داكناً في الوضعين. الشريط الجانبي وحده يُعاد تلوينه.

## بطاقة المشاركة

معظم منصات التواصل تتجاهل `og:image` بصيغة SVG، لذلك البطاقة PNG حقيقي:

```bash
npm run render:og
```

الخط العربي مُضمَّن من `node_modules` لا من الشبكة، فيظهر النص صحيحاً لا مربعات. السكربت **يقيس** حدود كل عنصر ويفشل إذا خرج أي منها عن الإطار، فلا تُنشر بطاقة مقصوصة بصمت.

عند تغيير النص أو الهوية، أعد تشغيل السكربت وأرفق الـPNG الناتج.

## الاختبارات

`tests/browser/motion.spec.ts` يعمل مع **تشغيل** الحركة، لأن المجموعة الأساسية تثبّت `reducedMotion: 'reduce'` ولا تلمس طبقة الموشن أبداً. يغطّي:

- الظهور عند التمرير ينتهي بعتامة كاملة، والميل يستجيب ويُنظَّف.
- تقليل الحركة: لا ميل، لا لمعة، ولا محتوى مخفي.
- الاسم موجود في العنوان والـHero والشريط الجانبي وشريط الجوال.
- رسم الـHero على الجوال لا يتراكب مع نصّه (اختبار انحدار بعد إضافة سطر الاسم).
